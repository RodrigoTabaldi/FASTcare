# FastCare screenshots

This directory is reserved for real screenshots of the FastCare interface. The repository currently has illustrations in `public/images/`, but no page screenshots.

Add genuine captures using these filenames, then uncomment their image references in the root `README.md`:

- `home.png` — landing page
- `fast-stages.png` — interactive FAST stages
- `checklist.png` — observation checklist
- `care-guidance.png` — daily care guidance

Do not use illustrations or mockups as screenshots of the running site.
